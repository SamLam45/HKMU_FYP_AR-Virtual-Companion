# Examples
[English](README.md) | [中文版](README_zh.md)

This folder contains example code and FlutterFlow custom-code references for testing the plugin's AR features.

The examples are reference implementations rather than part of the main application runtime. Some examples depend on optional third-party packages that are not included in the main app.
